# Simple Scientific Calculator
###### Made by Kenny Bee Utomo, for Algorithms & Programming class

### Basic Usage
Input:
```
<number> <operator> <number> <operator> <number> <operator> <number> ...
```
Example:
```
3 * 4
```
Output:
```
> 12.00
```
You can chain the output with more inputs:
```
> 12.00 * 100 + 20
```
Output:
```
> 1220.00
```
When satisfied, quit using `q`:
```
> 1220.00 q
```

### Operators
```
+		Addition
-		Subtraction
*		Multiplication
/		Division
%		Modulo
^		Exponent/Power
r		Root
=		Set value
```

### Unary Operators
```
q		Quit
(		Floor
)		Ceiling
_		Round
!		Negate
p		Set to PI
s		sin
c		cos
t		tan
S		asin
C		acos
T		atan
l		ln
L		log10
```

### Options
```
-q      Quiet mode, only output result on quit
```

### Notes
- No operator precedence
- Whitespaces are ignored
